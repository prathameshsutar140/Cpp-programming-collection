## ⚙️ Getting Started

### Requirements
- A C++ compiler such as GCC (g++)
- A code editor or terminal

### Compile and run

Compile one source file at a time:

```bash
g++ path/to/program.cpp -o program
./program
```

Example:

```bash
g++ Classes-and-Objects/PR4EX1.CPP -o class_demo
./class_demo
```

On Windows, run the generated executable:

```bash
program.exe
```

> **Tip:** Each source file is generally a separate practical program. Compile files individually unless the program's own instructions specify otherwise.
