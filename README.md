## Compile and run

Install a C++ compiler such as GCC. Open a terminal in the repository folder and compile one source file at a time:

```bash
g++ path/to/program.cpp -o program
./program
```

For example:

```bash
g++ Classes-and-Objects/PR4EX1.CPP -o class_demo
./class_demo
```

On Windows, run the generated executable as `program.exe`.
